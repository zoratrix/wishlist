# Интерфейс: структура страниц и мобильный UX (проект, этап 0)

## 1. Принципы

1. **Mobile First**: сначала проектируем экран телефона (360–430 px), затем
   планшет и компьютер. Вёрстка строится от мобильной.
2. **Современное приложение с олдскульной удобностью**: минимум декора,
   максимум читаемости, никаких «магазинных» баннеров и больших картинок.
3. **Не магазин**: вишлист — это список. Главный экран работы — быстрый ввод
   подарков, а не витрина.
4. **Одно действие — одна явная кнопка.** Никаких многошаговых «мастеров».
5. **Все состояния продуманы**: загрузка, пусто, ошибка, успех, подтверждение.
6. **Крупные цели нажатия** (≥ 44 px), шрифт интерфейса ≥ 16 px, поля ввода не
   вызывают автоматический зум на iOS.
7. **Русский язык** интерфейса, простые формулировки, без технических терминов.

## 2. Оформление (дизайн-токены)

- Шрифт: системный стек (`-apple-system, Segoe UI, Roboto, sans-serif`) —
  быстрая загрузка без внешних файлов.
- Палитра: тёплый нейтральный фон (`#faf8f5`), тёмный текст (`#23211f`),
  **один акцентный цвет** для действий (`#c2410c` — тёплый терракотовый, «не
  магазинный»), служебные цвета: успех `#15803d`, ошибка `#b91c1c`,
  предупреждение `#a16207`.
- Скругления 10–12 px, тонкие границы, тени почти отсутствуют.
- Никаких анимаций длиннее 150 мс; уважать `prefers-reduced-motion`.
- Тёмная тема — **не в MVP** (возможна на этапе 5).

## 3. Каркас навигации

**Телефон (основной):**
- Верхняя панель: название страницы + действия.
- Нижняя панель (таб-бар, 3–4 пункта, всегда под рукой):
  `Мои списки` · `Уведомления` · `Профиль`.
- Плавающая кнопка «＋ Подарок» на экране вишлиста (в зоне большого пальца).

**Планшет/компьютер:**
- Левое меню (те же пункты) + широкая рабочая область; нижняя панель скрыта.

**Гость (не залогинен):** только публичные страницы, вверху «Войти».

## 4. Страницы

| Путь | Назначение | Ключевые элементы |
|---|---|---|
| `/` | Вход/лендинг | если гость — короткое объяснение «что это» + кнопки «Войти»/«Регистрация» + Яндекс ID; если залогинен — сразу `/app` |
| `/login` | Вход | email, пароль, «Войти», «Забыли пароль?», «Вход через Яндекс» |
| `/register` | Регистрация | email, пароль, имя, логин (с проверкой занятости), чекбокс «присылать уведомления на почту» (по умолчанию включён, можно снять) |
| `/verify-email` | Подтверждение почты | текст + кнопка «Отправить письмо ещё раз» + «Продолжить без подтверждения» (аккаунт работает, показывается мягкий баннер) |
| `/forgot-password` | Восстановление | поле email, нейтральный ответ «Если аккаунт есть — письмо отправлено» |
| `/reset-password` | Новый пароль | по ссылке из письма |
| `/app` | Мои вишлисты | карточки списков: название, обложка (маленькая), число подарков, дата/повод, бейдж видимости; кнопка «＋ Новый список» |
| `/app/lists/:id` | Редактор вишлиста | **главный экран**: таблица/карточки, поиск, фильтры, сортировка, статусы, «＋ Подарок», меню (настройки доступа, экспорт, поделиться) |
| `/app/lists/:id/settings` | Настройки списка | название, описание, обложка, дата, видимость, переключатели «Показывать забронированные», «Показывать, кто забронировал», удаление |
| `/app/notifications` | Уведомления | лента, непрочитанные выделены, «Отметить все прочитанными» |
| `/app/profile` | Мой профиль | публичный вид собственного профиля + кнопка «Редактировать» |
| `/app/settings` | Настройки | данные профиля, приватность, уведомления, email, пароль, Яндекс ID, экспорт и **удаление аккаунта** |
| `/app/followers`, `/app/following` | Подписки | только владелец |
| `/u/:username` | Публичный профиль | имя, аватар, описание, ДР (месяц/день), видимые вишлисты, «Подписаться»/«Вы подписаны» |
| `/w/:token` | Публичный вишлист | заголовок, описание, владелец, подарки, кнопки бронирования/отмены; **это ссылка, которую рассылают** |
| `*` | 404 | понятный текст + «На главную» |

## 5. Главный экран — подарки в редакторе

Два режима: **«Таблица»** (по умолчанию) и **«Карточки»** (см. 7.1). На телефоне
горизонтальной прокрутки нет: таблица превращается в список компактных строк.

### 5.1. Ширина страницы

- Редактор вишлиста и публичная страница используют **всю доступную ширину**:
  контейнер `max-w-[1440px]` с отступами 16/24/32 px на телефоне/планшете/
  компьютере, шапка той же ширины.
- Списки, настройки списка и профиль — уже (`max-w-5xl`): длинные формы не
  должны растягиваться на весь экран.
- Таблица занимает 100% ширины, колонки пропорциональны — никаких «узких
  колонок по центру». На 768–1024 px колонка «Описание» скрывается, чтобы
  таблица не сжималась; с 1024 px показываются все колонки.

### 5.2. Таблица в стиле Excel/Notion

Главная идея: подарок заполняется **сразу целиком, в одной строке**, без
промежуточной кнопки «Редактировать».

Колонки таблицы на компьютере (≥1024 px):
`№ | Название | Описание | Приоритет | Цена | Ссылки | Статус | Действия`.

- **Описание — полноценная колонка** (около 30% ширины): текст переносится,
  показывается до 3 строк. Клик → редактирование в textarea (`Enter` —
  сохранить, `Shift+Enter` — новая строка, `Esc` — отмена, клик мимо —
  сохранить). Пустое описание допустимо.
- Внизу таблицы — **строка добавления** с полями в тех же колонках:
  `Название | Описание | Приоритет | Цена | Ссылки`; **описание — обычное поле
  в этой же строке** (textarea), без «＋ Описание» и без отдельной строки снизу.
- **Несколько ссылок:** поле «Ссылка на товар» + кнопка «＋ Ещё ссылка»
  (до 10) и «✕ убрать» у каждой; в один подарок можно вписать несколько
  вариантов (например, плед из разных магазинов).
- **Ссылки в описании становятся кликабельными автоматически:** `http/https`
  URL в тексте описания рендерится ссылкой (новая вкладка), остальной текст — как
  обычно, переносы строк сохраняются. Кнопками они не становятся.
- **Отображение ссылок — маленькие квадратные кнопки-иконки без подписи:**
  известные магазины получают фирменный цвет и монограмму (Ozon — синий «O»,
  Wildberries — фиолетовый «WB», Яндекс Маркет — красный «Я» и т.д.),
  неизвестные домены — нейтральная кнопка с иконкой глобуса. Подсказка при
  наведении — домен; иконка сайта (favicon) подгружается по возможности, при
  отсутствии сети остаётся монограмма/глобус. Размеры: 32×32 в таблице,
  36–40 в карточках/модалке. **До 6 ссылок видно сразу**, больше — «＋N».

`Enter` в любом однострочном поле = добавить подарок со всеми заполненными
полями (один запрос), очистить строку и вернуть фокус в «Название» — можно
вносить подарки подряд, не отрывая рук от клавиатуры. Кнопка «Добавить» делает
то же. Пустое название не отправляется.
- **Существующие строки правятся прямо в ячейках:** клик по названию, цене,
  приоритету или описанию превращает его в поле; `Enter`/клик мимо — сохранить
  (отправляется только изменённое поле), `Esc` — отменить. Ошибка показывается в
  ячейке, введённый текст не теряется.
- **Полное редактирование — в модальном окне** по кнопке-иконке карандаша
  (в колонке «Действия»; текстовая кнопка «Детали» убрана). Модалка: название,
  **описание сразу видимым обычным полем**, цена, приоритет, ссылки, категории,
  статус «уже подарен», перестановка ↑/↓, кнопки «Сохранить / Удалить / Отмена».
  Сохранение уходит одним запросом (только изменённые поля).
- Телефон: компактные строки (№, название, цена, приоритет, статус, первая
  ссылка + «+N»), иконка-карандаш открывает ту же модалку (bottom-sheet); кнопка
  «＋ Подарок» открывает форму со всеми полями (вертикально, с подписями), где
  описание — такое же обычное поле, и остаётся открытой для следующего подарка.

**Компактная строка (высота ~64 px):**
```
┌────────────────────────────────────────────┐
│ ①  Название подарка                1 500 ₽ │
│    ● Нужно  ·  Забронировано   [O] [WB] ▸  │
└────────────────────────────────────────────┘
```
- № и название — крупно; цена — справа, ссылки — квадратными кнопками-иконками.
- Вторая строка: приоритет (цветная точка + подпись), статус, ссылки.
- Тап по строке или карандаш → модальное окно редактирования (название,
  описание, цена, приоритет, список ссылок, категории, статус) с кнопками
  «Сохранить»/«Удалить»/«Отмена».

**Карточки:** сетка 1 / 2 / 3 / 4 колонки (телефон / планшет / компьютер /
широкий экран); в карточке — заголовок, цена, бейджи приоритета и статуса,
описание до 4 строк (ссылки внутри кликабельны), ссылки квадратными кнопками,
действия.

**Ссылки:** квадратная кнопка-иконка с фирменным цветом/монограммой магазина
(или нейтральная с глобусом), открывается в новой вкладке; до 6 ссылок видно
сразу, при большем числе — «＋N» с раскрытием.

**Ссылка на вишлист — короткая:** сервер выдаёт код из 7 символов, поэтому адрес
выглядит как `/w/k7M2pQ9` (≈ 9 символов пути). Кнопка «Поделиться» копирует
полный адрес с доменом. Если у списка осталась старая длинная ссылка, рядом
появляется кнопка **«Сократить ссылку»** — она перевыпускает код (с
подтверждением: старая ссылка перестанет работать). Ранее выданные длинные
ссылки продолжают работать, пока их не перевыпустят.

## 6. Бронирование — экран гостя

1. Подарок со статусом «свободен» → кнопка **«Забронировать»** (крупная,
   акцентная).
2. Открывается нижняя панель (bottom sheet) на телефоне / модальное окно на
   компьютере:
   ```
   Забронировать подарок
   «Наушники Sony WH-1000XM5»

   Ваше имя      [____________]
   Электронная   [____________]
   почта
   (email нужен только для возможности отменить бронь)

   [   Забронировать   ]
   ```
3. После подтверждения — зелёное сообщение «Готово! Подарок забронирован.» и
   подпись: «Отметка «Забронировано вами» хранится только в этом браузере — по
   ней вы сможете отменить бронь.»
4. Подарок, забронированный вами в этом браузере, помечается бейджем
   **«Забронировано вами»**. Отмена: кнопка «Отменить бронирование», email уже
   подставлен (поле остаётся редактируемым).
5. Ошибки: «Подарок уже забронировали» / «Проверьте email» / «Слишком много
   попыток, попробуйте позже».
6. Никаких регистраций, кодов, переходов на другие страницы и писем.

**Отмена:** у занятого подарка — «Занят» и кнопка «Отменить бронирование».
Окно: одно поле email + кнопка «Отменить». Успех: «Бронирование отменено».
Неудача: «Не удалось отменить бронирование. Проверьте email, который указывали
при бронировании.» (без подсказок о сохранённом адресе).

## 7. Публичный вишлист — вид гостя

- Шапка: название, описание, дата/повод, имя владельца, количество подарков.
- В шапке есть владелец: аватар, имя, @логин и кнопки **«Профиль»** (переход на
  `/u/:username`) и **«Подписаться» / «Вы подписаны»** (повторный клик
  отписывает). Гостя кнопка подписки ведёт на `/login` с возвратом на вишлист.
  Если профиль владельца закрыт, кнопок нет — остаётся только имя (факт
  существования закрытого профиля не раскрывается сверх уже видимого имени).
- Подарки в выбранном режиме (см. 7.1): у занятых — метка «Занят», у
  забронированных вами — «Забронировано вами», у подаренных — «Подарен».
- Владелец, открывший свою же ссылку незалогиненным, видит гостевой вид — это
  ожидаемо и объясняется подсказкой.
- Внизу: «Это вишлист — список желаний. Подарки можно бронировать без
  регистрации».

### 7.1. Режимы отображения подарков: «Таблица» / «Карточки»

Переключатель есть **и в редакторе своего списка, и на публичной странице**;
выбор запоминается в браузере (общий для обеих страниц). Режима «Строки» нет —
он оказался лишним.

| Режим | Телефон | Компьютер (≥1024px) |
|---|---|---|
| **Таблица** (по умолчанию) | компактные строки 64px без горизонтальной прокрутки: №, название, цена, приоритет, статус, первая ссылка (+N) | таблица во всю ширину: №, Название, **Описание (30%)**, Приоритет, Цена, Ссылки, Статус, Действия; правка прямо в ячейках, строка добавления внизу (см. 5.2) |
| **Карточки** | одна колонка карточек: заголовок, цена, бейджи приоритета и статуса, описание (до 4 строк), все ссылки кнопками, действия | сетка 2–4 колонки |

Кнопки ссылок — **маленькие квадратные иконки** с фирменным цветом и монограммой
магазина (Ozon синий, Wildberries фиолетовый, Яндекс Маркет красный, остальные по
карте), неизвестные домены — нейтральная кнопка с глобусом; открываются в новой
вкладке. До 6 ссылок видно сразу, больше — «＋N». Нет ссылок — кнопок нет. Ширина
контейнера — адаптивная: до 1440px на компьютере, формы — уже (см. 5.1).

В редакторе в обоих режимах работают: добавление, правка, перестановка ↑/↓,
удаление, переключатель «уже подарен». На публичной странице — бронирование и
отмена.

### 7.2. «Мои брони» для гостя (без регистрации)

Сервер по ТЗ не знает, кто вы, поэтому отметка «Забронировано вами» хранится
**только в вашем браузере** (localStorage): запоминаются ссылка, подарок, имя и
email, указанные при бронировании. Это не раскрывает данные другим посетителям
и не меняет серверную модель приватности.

- После брони подарок помечается «Забронировано вами», отмена открывается с уже
  подставленным email.
- Если очистить данные браузера или зайти с другого устройства, отметка
  исчезнет — но отменить бронь по-прежнему можно, введя email вручную.
- Если localStorage недоступен (редкие настройки приватности), страница
  работает как раньше, просто без отметки.

### 7.3. Категории (теги) в рамках вишлиста

Функция **опциональная**: пока категории не заведены, интерфейс выглядит как
раньше — ни чипов, ни фильтров.

- Категория принадлежит конкретному вишлисту; у подарка может быть **до 5
  тегов** (например, «Электроника» + «Подарок маме»).
- Чипы категорий показываются под названием подарка (в таблице), в карточках и в
  компактной мобильной строке.
- **Управление категориями — в редакторе вишлиста, сверху** (в настройках списка
  его нет): единая панель над подарками с фильтром «Все + категории + Без
  категории», кнопкой **«＋ Категория»** (inline-поле, Enter — создать) и режимом
  **«Изменить / Готово»**, в котором у категорий появляются «✎» (переименовать
  inline) и «×» (удалить с подтверждением «подарки останутся, теги снимутся»).
- **Цвет категории:** при создании (и в режиме «Изменить») выбирается из
  **палитры 8 цветов**: красный `#A9544C`, оранжевый `#B36A42`, янтарный
  `#A98A45`, зелёный `#4F7A5B`, бирюзовый `#47787A`, синий `#4C6B92`,
  фиолетовый `#6B5A8E`, розовый `#9A5F7C`. Если цвет не выбран — категория
  нейтральная (все такие категории выглядят одинаково). Чипы категорий красятся
  светлой подложкой выбранного цвета + точкой/рамкой, текст остаётся тёмным для
  читаемости; цвет виден в фильтре, у подарков, в модалке и на публичной странице.
- Пока категорий нет — в панели только «＋ Категория» и подсказка «Добавьте
  категории, чтобы группировать подарки».
- Редактор, модальное окно подарка: блок «Категории» — назначить/снять
  существующие, **«＋ Новая категория»** создаёт и сразу назначает. В строке
  добавления — необязательный select «Категория».
- Публичная страница: чипы и фильтр видны, править категории нельзя.

### 7.4. Сортировка списка подарков

В тулбаре подарков (рядом с переключателем «Таблица / Карточки») — select
**«Сортировка»**, работает в редакторе и на публичной странице:

| Вариант | Как сортирует |
|---|---|
| **По порядку** (по умолчанию) | ручной порядок (перестановка ↑/↓) |
| Сначала новые / старые | по времени добавления |
| По алфавиту А–Я / Я–А | по названию (русский алфавит) |
| По цене ↑ / ↓ | подарки без цены — в конце |
| По приоритету | 1 (самый важный) сверху |
| По категориям | категории по алфавиту, без категории — в конце |
| Сначала свободные / занятые | по факту бронирования |

- Сортировка применяется **после фильтра** и в обоих режимах; номера строк —
  по текущему порядку.
- Выбор запоминается в браузере (`wl:sort:v1`).
- **Приватность:** у владельца при выключенном «Показывать забронированные»
  варианты «по занятости» скрыты — иначе сортировка раскрыла бы факт брони.
  Гостям они доступны (они и так видят «Занят»).
- Перестановка ↑/↓ доступна только в режиме «По порядку»; в остальных режимах
  показывается подсказка.

### 7.5. Социальные функции (этап 3)

- **Публичный профиль `/u/:username`:** аватар-заглушка (первая буква), имя,
  @логин, описание, день рождения (год — если разрешён владельцем), кнопка
  **«Подписаться» / «Вы подписаны»** (повторный клик отписывает), список видимых
  вишлистов карточками. Свой профиль — кнопка «Редактировать профиль» и
  счётчики подписчиков/подписок.
- **Подписка со страницы вишлиста:** в шапке чужого списка те же кнопки
  «Профиль» и «Подписаться»/«Вы подписаны», поэтому подписаться можно сразу из
  присланной ссылки, не заходя отдельно в профиль.
- **Подписки односторонние:** у каждого пользователя есть «Мои подписки» и «Мои
  подписчики» (`/app/following`, `/app/followers`; видны только владельцу):
  списки с аватаром-буквой, именем, @логином и bio; можно отписаться или удалить
  подписчика (с подтверждением).
- **Закрытый профиль:** посторонним такой профиль недоступен —
  «Профиль недоступен» (без раскрытия, существует ли он). Существующие подписки
  при закрытии профиля сохраняются.
- **Вишлист «Только подписчикам»:** третий вариант доступа в настройках списка.
  Прямая ссылка доступа не даёт: гостю показывается «Список доступен только
  подписчикам» с предложением войти; авторизованному не-подписчику — подсказка
  подписаться на владельца. Уведомления о подписке — этап 4.

## 8. Состояния и обратная связь

| Состояние | Как выглядит |
|---|---|
| Загрузка | скелетоны строк/карточек, не пустой экран |
| Пусто | иллюстрация-текст + главное действие («Добавьте первый подарок») |
| Ошибка сети | текст «Не удалось загрузить. Проверьте интернет» + кнопка «Повторить» |
| Успех | короткий тост внизу, исчезает через 3 с |
| Опасное действие | подтверждение в модальном окне: «Удалить вишлист? Это действие нельзя отменить» (кнопка «Удалить» красная, «Отмена» — обычная) |
| Нет прав | 404-подобный экран «Страница не найдена или недоступна» (не раскрывать существование приватного списка) |

## 9. Доступность и качество

- Контраст текста ≥ 4.5:1; иконки дублируются текстом.
- Все интерактивные элементы доступны с клавиатуры и имеют видимый фокус.
- `<label>` связаны с полями; ошибки озвучиваются (aria-live для тостов).
- Изображения с `alt`, декоративные — без него.
- Проверка на ширинах: 320, 360, 390, 768, 1024, 1440 px.

## 10. Что НЕ делаем в интерфейсе

- Тёмную тему, анимации-«вау», parallax — не в MVP.
- Горизонтальную прокрутку таблицы на телефоне.
- Всплывающие баннеры, cookie-баннеры «как в магазинах» (нужен только
  минимальный баннер о персональных данных по требованию законодательства —
  обсудить на этапе публикации).
- Бесконечные «онбординги» и туториалы.
