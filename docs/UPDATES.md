# Обновления для уже развёрнутого сайта

Короткие инструкции для администратора уже работающего сайта: что изменилось,
нужно ли что-то делать с базой и как обновить контейнер. Свежие записи — сверху.

**Как обновляться всегда:** в папке проекта на сервере выполнить
`./deploy/update.sh` (это `git pull --ff-only` + `docker compose up -d --build`).
Если обновление делается вручную — те же две команды по очереди.

---

## 2026-11-24 — Кнопки «Профиль» и «Подписаться» на публичном вишлисте

**Что было не так.** Друг открыл присланную ссылку на вишлист: имя владельца
видно, но перейти в его профиль и подписаться было нельзя.

**Что изменилось.**
- В шапке публичного вишлиста появился блок владельца: аватар, имя, @логин,
  кнопка **«Профиль»** (открывает `/u/:username`) и кнопка
  **«Подписаться» / «Вы подписаны»** (повторный клик отписывает).
- Гость, нажимая «Подписаться», попадает на страницу входа и после входа
  возвращается на тот же вишлист.
- Если владелец закрыл профиль, кнопок нет — имя остаётся, чужие данные не
  раскрываются.
- Сервер: `GET /api/w/:shareToken` теперь возвращает поле
  `viewer: { isSelf, isFollowing, canFollow }` (отношение смотрящего к
  владельцу). Правила те же, что у публичного профиля.

**Нужно ли что-то в базе.** Нет. Миграций нет, схема БД не меняется; `.env`,
`data/` и загруженные картинки не трогаются.

**Как обновить.**
```bash
cd /путь/к/проекту
./deploy/update.sh
```
или вручную:
```bash
git pull --ff-only
docker compose up -d --build
```

**Как проверить после обновления.**
1. `docker compose ps` — контейнер `app` в статусе `running`.
2. Откройте чужую ссылку вишлиста в режиме инкогнито: в шапке должны быть
   аватар и имя владельца, кнопки «Профиль» и «Подписаться».
3. Войдите вторым аккаунтом и нажмите «Подписаться» — кнопка станет
   «Вы подписаны», владелец увидит нового подписчика в `/app/followers`.
4. Если видите старую версию — жёсткое обновление страницы (Ctrl+Shift+R):
   браузер мог закэшировать старый JS.

**Если что-то пошло не так.**
- Логи: `docker compose logs -f app`.
- Белый экран после обновления: пересобрать `docker compose up -d --build`,
  затем Ctrl+Shift+R в браузере.
- Откат: `git log --oneline` → `git checkout <предыдущий-коммит>` →
  `docker compose up -d --build`. Базу откатывать не нужно — схема не менялась.
