## 2026-11-13 — Цвета категорий и короткие ссылки на вишлист

**Добавлено**
- **Цвет категории:** миграция `004_category_color.sql` (`categories.color TEXT
  NULL`); палитра из 8 цветов (`#DC2626`, `#EA580C`, `#CA8A04`, `#16A34A`,
  `#0D9488`, `#2563EB`, `#7C3AED`, `#DB2777`); `CategoryDTO {id, name, color}`;
  POST/PATCH категорий принимают `color`, невалидный → `400 INVALID_COLOR`,
  `null` — «по умолчанию». В интерфейсе: ряд свотчей при создании и смене цвета;
  чипы категорий (фильтр, подарки, модалка, публичная страница) — светлая
  подложка цвета + точка/рамка, текст тёмный; без цвета — единый нейтральный вид.
- **Короткие ссылки:** `shareToken` нового вишлиста — 7 крипто-случайных символов
  `[A-Za-z0-9]` (ссылка вида `/w/k7M2pQ9`), коллизии обрабатываются повтором;
  ранее выданные длинные токены не меняются и продолжают открывать страницы.
  Seed использует короткие токены и демо-цвета категорий.
- Сервер: `lib/schemas.ts` (палитра), `lib/crypto.ts` (`newShareToken`),
  модуль категорий, seed; клиент: `lib/category-colors.ts`, панель категорий,
  цветные чипы.

**Проверено**
- `npm test` → **106/106** (сервер; +12: цвет категорий 7, short-token 5) +
  **118/118** (сайт; +9).
- `npm run typecheck`, `npm run build` — без ошибок.
- `npm run e2e:smoke` (реальный сервер, прод-сборка) → **58/58**, включая
  7-символьный токен, цвет категории, 400 на невалидный цвет и цвет в публичном
  виде.
- Миграция 004 применена к рабочей базе: данные целы, старые токены рабочие,
  старые категории получили `color = NULL`.

**Ограничения**
- Палитра фиксирована в коде (расширение — правка `lib/schemas.ts`, миграция не
  нужна, CHECK в БД нет).
- Свотчи — всегда видимый ряд, без выпадающего пикера.
- Категория, созданная из модалки подарка, получает цвет «по умолчанию» (сменить
  можно в верхней панели).
- Короткий токен — 7 символов: перебор 62⁷ (~3,5 трлн) неосуществим, но ссылка
  чуть менее «секретна», чем длинная; при необходимости длину легко увеличить.
