# Вишлисты — веб-платформа списков желаний

Платформа для создания вишлистов с социальными функциями и **бронированием
подарков без регистрации**. Интерфейс на русском языке, мобильная версия —
приоритет.

**Текущий статус: рабочая версия (MVP + соцфункции + уведомления на сайте + сброс пароля).**
Работает: регистрация и вход, профиль с аватаром, вишлисты, подарки (таблица в
стиле Excel/Notion и карточки), несколько ссылок на подарок, категории-теги с
цветами, сортировка, темы и обложки вишлистов, эмодзи-фон, короткие ссылки,
публичная страница, бронирование без регистрации, «Забронировано вами»,
скрытие броней от владельца, подписки и публичные профили (подписаться можно
и прямо со страницы вишлиста), лента, видимость
«только подписчикам», восстановление пароля по email.
347 автотестов + 75 проверок реального API — зелёные.

**Развёртывание:** Docker — см. [DEPLOY.md](DEPLOY.md).

## Быстрый старт

На компьютере нужен только **Node.js LTS** — скачать: https://nodejs.org/ru.
База данных и почтовый сервер отдельно не устанавливаются.

**Самый простой способ:** дважды щёлкните файл **`start.cmd`** в папке проекта —
он сам создаст базу при необходимости, запустит сайт и откроет браузер.

Через терминал (в папке проекта!):

```bash
npm install                  # один раз: установить зависимости
copy .env.example .env       # затем заменить оба секрета (шаг 6 в docs/RUN.md)
npm run db:migrate           # создать базу данных
npm run db:seed              # добавить тестовые данные
npm run dev                  # запустить сайт и сервер
```

Откройте http://localhost:3000 — страница «Вишлисты» с отметками «Сервер» и
«База данных» зелёного цвета.

> Подробная пошаговая инструкция для новичка (что установить, как проверить,
> что делать при ошибках): **[docs/RUN.md](docs/RUN.md)**.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | сайт + сервер на http://localhost:3000 (Vite + Express в одном процессе) |
| `npm run dev:watch` | то же, но с авто-перезапуском при изменении серверного кода |
| `npm test` | автотесты сервера и сайта (347 тестов) |
| `npm run e2e:smoke` | проверка реального API (нужен запущенный сервер; 75 проверок) |
| `npm run typecheck` | проверка типов TypeScript |
| `npm run build` | собрать сайт в `web/dist` и сервер в `server/dist` |
| `npm start` | запуск собранной версии (после `npm run build`) |
| `npm run db:migrate` | применить миграции базы данных |
| `npm run db:seed` | тестовые данные |
| `npm run db:backup` | резервная копия базы в `backups/` |

```

│   │   ├── app.ts          # сборка Express-приложения
│   │   ├── dev.ts          # режим разработки (Vite внутри Express, один порт)

│   │   └── routes/         # API-роуты
│   ├── db/migrations/      # SQL-миграции (001_init.sql — вся схема)
│   ├── tests/              # тесты (Vitest + Supertest)
│   └── data/app.db         # база данных (создаётся автоматически, не в Git)
├── web/                    # frontend: React + Vite + TypeScript + Tailwind
│   └── src/                # страницы, компоненты, стили
├── docs/                   # проектная документация
├── uploads/                # загруженные картинки (не в Git)
├── backups/                # резервные копии базы (не в Git)
├── .env.example            # пример настроек без секретов
└── README.md
```

## Главные правила проекта

- Пароли не хранятся в открытом виде, секреты — только в `.env`.
- Бронирование без регистрации: имя + email, одна кнопка, без подтверждений.
- У подарка не может быть двух активных броней (гарантия на уровне базы).
- Владелец по умолчанию не видит бронирования; email бронирующих не видит никто.
- Все проверки прав и приватности — на сервере.
